# CSC 111: Computer Programming 1

My introduction to Java projects from Computer Programming 1 at Farmingdale State College. The programs below are listed in the order the skills build, from basic input and output through decisions, loops, methods, and arrays, ending with larger programs that combine them.

**Language:** Java

**Note:** Files were submitted as `Program.java` for the course and renamed here to describe each program.

## 1. Input, Output, and Variables
| File | What it does |
|------|--------------|
| `NameGreeting.java` | Reads a name with Scanner and prints a greeting |
| `ch3_InputLab.java` | Reads a String, int, double, and char and prints them back |
| `ch3_CoffeeReceipt.java` | Formats a receipt with printf (alignment and decimal places) |
| `ch3_Invoice_Hw.java` | Prints an aligned item table from user input |
| `ch3_Lab.java` | Reads mixed input (city, price, attendees, section) and prints an event summary |
| `ch3_Warehouse_Inventory_Tracker_Hw.java` | Parses a line of inventory data with a second Scanner and calculates total value |

## 2. Decisions (if / else)
| File | What it does |
|------|--------------|
| `ch4_Movie_Ticket_Pricing_If-Else.java` | Sets a ticket price based on age |
| `ch4_Coffee_Price_Calculator_Hw.java` | Chooses a price from the coffee size using String comparison |
| `ch4_Letter_Grade_Logger.java` | Converts a numeric score to a letter grade with if / else if chains |

## 3. Loops
| File | What it does |
|------|--------------|
| `Multiplier_Table.java` | Prints a multiplication table with a for loop |
| `Range_Protector.java` | Uses a do-while loop to validate an access code |

## 4. Methods
| File | What it does |
|------|--------------|
| `Temperature_Converter.java` | Converts Fahrenheit to Celsius using methods with return values |

## 5. Arrays
| File | What it does |
|------|--------------|
| `Array_Demo.java` | Reads three integers into an array with a for loop and prints them back |
| `Parallel_Arrays.java` | Uses parallel arrays of names and scores to print a grade report |
| `Parallel_Arrays_With_Method.java` | Same grade report, refactored into a method |

## 6. Larger Programs
| File | What it does |
|------|--------------|
| `Budget_Tracker.java` | Tracks a monthly budget with a loop that subtracts expenses until you enter 0, warning you if you go over |
| `GreenHorizon.java` | Menu-driven inventory and sales program for a garden store, using parallel arrays, methods, input validation, and sales tax |
